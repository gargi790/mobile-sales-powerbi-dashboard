# 📱 Mobile Sales Analysis Dashboard | Power BI

An interactive **Power BI dashboard** designed to analyze mobile sales performance and provide meaningful business insights through data visualization and interactive reporting.

The dashboard focuses on sales trends, transaction performance, product analysis, customer behavior, and time-based performance metrics.

---

## 📊 Dashboard Overview

The Mobile Sales Dashboard provides a centralized view of key sales performance indicators and allows users to explore the data using interactive filters and visualizations.

### Key KPIs

- 💰 Total Sales
- 📦 Total Quantity Sold
- 🧾 Total Transactions
- 📈 Average Sales
- 📅 Monthly Sales Performance
- 🏷️ Brand & Product Performance
- 💳 Payment Method Analysis
- 📍 Geographic Sales Analysis

---

## 🚀 Key Features

### 1. Sales Performance Analysis
- Overall sales and transaction performance
- Monthly and daily sales trends
- Quantity and revenue analysis
- Average sales performance

### 2. Product Analysis
- Sales performance by mobile brand
- Product/model-wise analysis
- Top-performing products
- Quantity sold by product category

### 3. Customer & Transaction Analysis
- Transaction-level insights
- Payment method distribution
- Customer purchase patterns
- Sales contribution across different segments

### 4. Time Intelligence
- Monthly performance tracking
- MTD (Month-to-Date) analysis
- Year-over-Year comparison
- Same Period Last Year comparison

### 5. Interactive Dashboard
The report includes interactive slicers and filters that allow users to drill down into specific:

- Dates
- Brands
- Mobile models
- Cities
- Payment methods
- Sales metrics

## 🔄 Data Preparation

The data was prepared and transformed before visualization using Power Query.

The data preparation process includes:

- Data type correction
- Data cleaning
- Column transformation
- Handling missing/inconsistent values
- Creating analysis-ready fields
- Preparing data for DAX calculations

---

## 🧮 DAX & Analytics

The dashboard uses DAX measures to calculate important business metrics and support time-based analysis.

Examples include:

- Total Sales
- Total Quantity
- Total Transactions
- Average Sales
- MTD Sales
- Previous Year Sales
- Same Period Last Year
- Sales Growth %

These calculations enable dynamic reporting based on the selected filters.

The dashboard can be used to identify:

- Monthly sales trends
- Sales contribution by location

- Products contributing most to overall revenue
